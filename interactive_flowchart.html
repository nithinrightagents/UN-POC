Stage 3a • ADK Session
🎯 Component Purpose
Evaluates a specific UN assessment question against rendered portal DOM content using an isolated Google ADK agent session.
📥 Closed Input Schema
{ "session_id": "sess_2026_0813", "agent_index": 0, "round_number": 1, "question": { "question_id": "Q14_OPEN_DATA", "text": "Does national portal provide an open data link?", "answer_type": "binary" }, "portal": { "portal_id": "P_FRA", "resolved_url": "https://www.data.gouv.fr" } }
📤 Output Payload
{ "run_id": "run_9941a", "answer": "YES", "confidence": 87, "justification": "Page explicitly features open data portal link in footer.", "evidence": { "resolved_url": "https://www.data.gouv.fr", "element_reference": { "css_path": "footer > a.data-link", "text_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4" } } }
🔒 Structural Invariants & Rules
✓ Strict Independence: Schema is closed. Cannot see ground truth or other agent answers.
⚠️ Confidence Gate: If confidence < 75, agent retries once with self-critique.
🚫 Auth Walls: If authentication boundary is detected, answer MUST be null.

Agent & System Component Specification Matrix

Detailed specifications of all multi-agent roles, inputs, outputs, retries, and failure modes in the UN EKAP AIQ pipeline.
Component / Agent Primary Function Input Schema Output Schema Retry & Escalation Limits
🔍 Link Resolution
 Discovers target page URLs via Prior KB → MSQ DB → Gov Search. (question_id, portal_id) Candidate usable URL + resolution source tag. Fallthrough across 3 sources. Escalates if unreachable.
🌐 Traversal & Render
 Live headless rendering, DOM capture, region screenshot & auth check. Candidate URL + Rate Limit token Rendered DOM, Screenshot, Language code, Auth flag. Per-domain token bucket rate limiting.
🤖 Assessor Agent 1 & 2
 Independent AI assessment of question against DOM evidence. Closed Schema (Question + DOM, NO cross-agent data). Binary/Enum Answer, Confidence (0-100), Evidence Citation. If Confidence < 75: 1 retry round with self-critique addendum.
🛡️ Validator Agent
 Re-fetches live URL and verifies element selector & text hash. Exactly ONE Assessor Agent output + Live URL. Pass/Fail, Quality score, Verified timestamp, Gap list. Up to 2 retries for failed agent. Escalates if < 2 agents pass.
⚖️ Mechanical Adjudicator
 Deterministic consensus building & discrepancy detection. Set of ≥ 2 Validated Agent outputs. Consensus Answer & Confidence OR Escalation Record. Up to 2 retry rounds with anonymized disagreement points.
👤 Human Review Surface
 UN Assessor web app for validating, editing, or overriding pre-fills. Pre-filled survey, Evidence citations, Escalation flags. Final approved assessment record + override reasoning.
