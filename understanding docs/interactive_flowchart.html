Core System Invariants
📋 Prefilled Blank Fallback Blocked units set answer=null with canonical reason tags; never block portal review.
🛡️ Structural Independence Fresh, stateless model call per assessor — zero shared memory or conversation history.
⚡ Shared Rate Limiter Single token bucket (0.5 req/s, capacity 5) throttles all fetches across every unit.
🗣️ Inline Language Check Self-reported ISO codes with majority-vote gating; no external detector package.
🔢 N-Agent Configurable Defaults to 2 assessors; pairwise combinations & voting generalize seamlessly to N.
🗺️ Portal-Level Lens Macro discrepancy detector evaluates aggregate first-round divergence across entire portals.
📝 Append-Only Ledger Reviewer edits create new records; system proposals remain immutable in audit provenance.
🧪 CLI Verification Guarantees verified via runnable commands: aiq verify resume / hygiene / no-credentials.

Stage 1 & 2 · Evidence Discovery & Browser Traversal
🔍
1. Link Resolution
Discovery Engine
  • 3-source fallthrough: Prior-Survey KB → MSQ Submissions → Gov-TLD Search.
  • Strict boundary: Discovers WHERE to look; never supplies or implies answers.
  • Exhausting all sources marks unit UNASSESSABLE with canonical reason tag.
Resolution:Historical First (3 srcs)
No URL:→ Blank + Reason Tag
🌐
2. Live Traversal
Playwright & Limiter
  • Independent live headless Playwright render inside each assessor's session.
  • Real token bucket: 0.5 req/s (1 token / 2s), burst 5, per domain.
  • 2-signal auth-wall detection sets answer=null with "Login barrier" reason tag.
Rate Limiter:0.5 req/s/domain
Auth Wall:→ Blank + Reason Tag

Stage 4 · Independent Verification & Coherence Checking
🛡️
4. Validator Agent
≤2 Retries · 3/3
Verification Engine
  • Grades exactly ONE agent's output; never compares agents to each other.
  • Live re-fetch relocates cited DOM element via CSS path & text hash (≤3 attempts).
  • Unverifiable targets fall back to blank field with "Evidence unverified" tag.
Re-verify:Fresh Fetch (≤3 att)
On Failure:→ Blank + Reason Tag
Stage 5 · Language Support Majority Gate
🗣️
5. Language Policy Check
Hard Gate
Inline Majority Vote
  • Tallies self-reported ISO language codes across all validated agent runs.
  • No external language detector package; LLM's own inline read is source of truth.
  • Unsupported majority language sets answer=null with "Unsupported language" tag.
Input Data:All Agent Language Tags
On Mismatch:→ Blank + Reason Tag
Stage 6 · Algorithmic Consensus Adjudication
⚖️
6. Adjudicator
≤2 Retries · All
Consensus Rules Table
  • Deterministic Python decision table; never uses a 3rd "judge" LLM.
  • Discrepancy flagged if answers differ OR confidence delta > 10 points.
  • Unresolved disagreements (after 2 retries) fall back to blank field with reason tag.
Discrepancy:Answer≠ OR Δ>10
Unresolved:→ Blank + Reason Tag
Stage 7 · Portal-Level Aggregate Discrepancy Lens
🗺️
7. Portal-Level Adjudicator
Portal Lens
Aggregate Rate Check
  • Evaluates whole portal divergence using FIRST-round (pre-retry) answers.
  • Flags whole portal if differing-answer rate or affirmative gap exceeds 10%.
  • Macro discrepancy alerts reviewer directly on the unified portal review screen.
Scope:Whole Portal (Round 1)
Threshold:10% Divergence
Stage 8 & 9 · Blank-Field Fallback Annotations & Prefilled Review
📋
8. Blank-Field Fallback
Blank = null
Canonical Reason Tags (FR-BF)
  • Blocked units set answer to null (blank) rather than forcing an unfounded guess.
  • Attaches deterministic canonical Reason Tags (e.g. "Left blank: Login barrier observed").
  • Carries visited URLs, screenshots & round attempt history as reviewer context.
Answer Value:null (Left blank)
Annotations:7 Canonical Templates
👤
9. Unified Portal Review
Unified View
Prefilled Questionnaire Web App
  • Single portal view displays all ~200 questions: answered prefilled, blocked blank.
  • One-click Approve on high-confidence answers; edit or fill in blanks directly.
  • Review of valid questions is never blocked by a single escalated question.
Review Surface:/portal/{id} Unified Set
Actions:Approve / Edit / Fill Blank

Assessor Agent 1

Stage 3a • Model Call (Index 0)
🎯 Component Purpose & Architecture
  • Evaluates UN assessment indicators against rendered portal DOM content.
  • Operates in total structural isolation with zero shared conversation memory.
  • Self-reports inline page language and element citations in one structured payload.
📥 Closed Input Schema
{ "session_id": "sess_2026_0813", "agent_index": 0, "round_number": 1, "question": { "question_id": "Q14_OPEN_DATA", "text": "Does national portal provide an open data link?", "answer_type": "binary" }, "portal": { "portal_id": "P_FRA", "resolved_url": "https://www.data.gouv.fr" } }
📤 Output Payload Schema
{ "run_id": "run_9941a", "answer": "YES", "confidence": 88, "justification": "Page explicitly features open data portal link in footer.", "evidence": { "resolved_url": "https://www.data.gouv.fr", "element_reference": { "css_path": "footer > a.data-link", "text_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4" } }, "detected_language": "fr" }
🔒 Structural Invariants & Guarantees
✓ Strict Independence: Closed schema. Cannot see ground truth or other agent answers.
⚠️ Confidence Gate: If confidence < 75, agent retries once with self-critique addendum.
🚫 Auth Boundaries: If login barrier detected, answer MUST be null & escalated.
